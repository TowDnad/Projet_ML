# EUR/USD Exchange Rate Prediction

This project focuses on forecasting the EUR/USD exchange rate using basic Machine Learning models and Time Series analysis and Xgboost. It compares different algorithms to predict the closing price based on historical data and evaluate which models would be suited for further prediction.

### Project Overview

In the EUR_USD_Prediction.ipynb you'll see: 
1. Data loading and preprocessing.
2. Data exploration to check missing values.
3. Model implementation (Linear Regression, Random Forest, XGBoost, ARIMA, etc.).
4. Performance evaluation.

### Necessary tools to run
**Python 3**
**IDE that can run jupyter notebooks**
